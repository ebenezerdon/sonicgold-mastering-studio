# SonicGold Mastering Studio

A professional-grade, browser-based audio mastering application built by [Teda.dev](https://teda.dev). 

## Features

*   **Drag & Drop Interface**: Seamlessly load tracks.
*   **Web Audio DSP Engine**: Real-time multiband compression, EQ, saturation, and limiting simulation.
*   **4 Mastering Profiles**:
    *   **Universal**: Balanced for all genres.
    *   **Fire**: Punchy, warm, saturated.
    *   **Clarity**: Bright, open high-end.
    *   **Retro**: Mid-focused, tape-style rollover.
*   **Visualizer**: Real-time frequency analysis and waveform navigation.
*   **A/B Comparison**: Instantly toggle between the original mix and the master (hold-to-compare).

## Tech Stack

*   HTML5 / CSS3
*   Tailwind CSS (via CDN)
*   jQuery 3.7.1
*   Web Audio API (No external libraries)

## How to Use

1.  Open `index.html` to view the landing page.
2.  Click "Launch Studio" to open the app.
3.  Drag an audio file (WAV/MP3) onto the drop zone.
4.  Select a preset style and adjust intensity.
5.  Export your mastered track.
